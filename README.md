## Sobre mim

- Construo **ferramentas para desenvolvimento com IA**: mods, orquestração de agentes e guardas de repositório para o **Claude Code**
- Desenvolvo o **Ragnarok Classic Idle**, um Ragnarok Online idle no navegador, com **servidor autoritativo em TypeScript** falando o protocolo do rAthena
- Venho do **trading algorítmico**: Expert Advisors em **MQL5**, robôs para MetaTrader 5 e automação de estratégias financeiras
- Gosto de provar o que construo: testes por mutação, provas visuais e nada de número inventado
